# App Store screenshots

`ru/` — eight screenshots for the App Store listing, 1290×2796 (the 6.7-inch
iPhone size App Store Connect accepts for the 6.9-inch slot), RGB without an
alpha channel, in display order.

Source: Figma «Школа Михаила Агеева / Согласование», section «На согласование»
→ «Скриншоты для App Store» (node 481:10054), exported 2026-11-28.

`01-home.png` differs from the Figma frame: the designer's phone screen showed
«Добро пожаловать, [Имя]», a sparkle button and a mini-player bar that the app
does not have, so the phone screen was replaced with a real capture of the
current home screen. Title, background and phone frame are the designer's.
